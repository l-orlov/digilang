# digilang

Landing de la agencia — React + Vite + TypeScript (mismo stack que zoocial), con WebGL (three.js / react-three-fiber) y GSAP para el motion.

### Run project
```
cd web/frontend
npm install
npm run dev
```

### Build de producción
```
cd web/frontend
npm run build   # genera web/frontend/dist
npm run preview # sirve el build localmente
```

El sitio PHP anterior (vanilla JS, i18n en 3 idiomas) quedó archivado en `web/legacy-php/` como referencia.
